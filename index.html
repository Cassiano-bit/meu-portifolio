Meus Projetos

As 7 Maravilhas do Mundo

Projeto desenvolvido em HTML, CSS e JavaScript sobre as 7 Maravilhas do Mundo, com carrossel automático de imagens, navegação manual por botões e links para a localização de cada monumento no Google Maps. O objetivo foi praticar estruturação de páginas, estilização e interatividade com JavaScript.

IF Ateliê

O IF Ateliê é um projeto desenvolvido para apresentar um ateliê de forma elegante e acolhedora no ambiente digital. O site reúne informações sobre a marca, seus produtos e trabalhos artesanais, valorizando a identidade visual e facilitando o contato com o público. O projeto foi construído utilizando HTML e CSS, com foco em uma navegação simples, organização do conteúdo e uma estética delicada que representa a proposta do ateliê.
